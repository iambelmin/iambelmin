## 🛠️ Recent Projects

### [Hopvane](https://hopvane.com)
*"Every hop, pointed right."* Short links and dynamic QR codes for print. You can change where a code points at any time, and the change takes effect from the next scan, with no reprinting.

- **QR designer:** colors, logo, eye shapes, frames and a call to action, with live contrast and quiet-zone checks
- **Analytics:** scans and clicks by time, country, device and referrer, with bots filtered out
- **Custom domains:** DNS setup wizard with automatic SSL
- **Safety:** destinations checked against phishing lists on creation and daily after that, plus a `+` link preview
- **Reliability:** each redirect node keeps its own copy of the link, so printed codes keep working even if the database goes down
- **Plans:** free tier plus paid plans, 2FA on every plan, and CSV/JSON export
- **Free static QR generator:** no sign-up needed

**Stack:** Next.js 16 · React 19 · TypeScript · PostgreSQL · Drizzle ORM · Better Auth · Stripe · Resend · Tailwind CSS · Netlify
